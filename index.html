Host-Validated Auto Counter

Host must be connected for counting to run. Host validates and increments everyone's score once per second.
Client: —
Creator (host): —
Counting behavior:
  • When the project creator (host) is connected and host-auto is enabled, the host will increment each connected user's leaderboard score by +1 per second.
  • If host disconnects, counting stops immediately.
  • Scores are stored in the persistent collection "leaderboard" (one row per user, id = user_id).
